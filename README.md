# STM32 Embedded Roadmap

Lộ trình 2 tháng học lập trình nhúng C/C++ trên STM32F103C8T6 (Blue Pill).
Mục tiêu: nền tảng vững + ECU giả lập (CAN, FreeRTOS, bootloader, UDS).

## Phần cứng
- Blue Pill STM32F103C8T6, ST-Link V2, logic analyzer 8 kênh

## Tiến độ
| Tuần | Nội dung | Trạng thái |
|---|---|---|
| 1 | Cortex-M3 bare-metal, clock 72 MHz | Đang làm |
| 2 | GPIO/EXTI/Timer/UART, HardFault | Chưa |
| 3 | ADC+DMA, SPI/I2C | Chưa |
| 4 | Kiến trúc phân lớp, unit test | Chưa |
| 5 | FreeRTOS | Chưa |
| 6 | CAN | Chưa |
| 7 | Bootloader + UDS | Chưa |
| 8 | ECU giả lập (repo riêng) | Chưa |
